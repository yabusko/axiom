Direction index

Two candidate visual directions, each applied to the same two wireframe screens (Landscape and the Research-gap detail / "bridge" view), for side-by-side comparison. Pick a direction before the shared design system gets written — don't blend them.

A — Field Ledger

Editorial / archival / evidence-ledger. Paper background, ink text, a single teal accent spent sparingly, amber badges only. Serif headlines, sans body, monospace for every number. 8px grid, 2px near-sharp corners, no shadows — hairline rules separate everything. Dense, row-based "ledger" lists.

Landscape Gap detail

B — Field Map

Cartographic / spatial / technical-map. Cool mist background, charcoal text, a coral marker reserved for the gap itself and the one primary action per screen, a muted teal wash coding topic "regions." One sans family throughout, tabular numerals, no monospace. 4px grid, sharp 0px corners, no shadows — left borders and grid-paper backdrops instead. Topics render as a sized tile grid, not a list.

Landscape Gap detail

What to compare

Both directions carry over the exact same data and copy from the wireframes (300 papers, 1,699 citations, 31 communities, 15 gaps on Landscape; the 43-paper NLP/ML cluster vs. 20-paper QA cluster at 98.8% similarity / 32 citations / G-score 0.618 on Gap detail). Only the visual treatment changes — typography, color, spacing, elevation, and layout concept (A is a flat row/ledger list; B is a spatial tile grid with grid-paper and region coding).
